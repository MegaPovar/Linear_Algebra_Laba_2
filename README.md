# Лабораторная работа 2

Тема: однослойный перцептрон для бинарной классификации.

## Запуск

```bash
pip install -r requirements.txt
python main.py
```

После запуска результаты сохраняются в папку `results/`.

## Что реализовано

- генерация бинарного набора данных с двумя числовыми признаками;
- стратифицированное разделение на обучающую и тестовую выборки;
- стандартизация признаков по обучающей выборке;
- однослойный перцептрон с сигмоидной активацией;
- бинарная кросс-энтропия;
- обучение мини-батчами;
- расчет accuracy;
- графики функции потерь;
- визуализация разделяющей прямой;
- эксперименты со скоростью обучения, размером батча и инициализацией весов.

## Файлы результатов

- `results/base_loss.png` - график loss для основного обучения;
- `results/decision_boundary.png` - разделяющая граница;
- `results/learning_rate_experiment.png` - влияние скорости обучения;
- `results/batch_size_experiment.png` - влияние размера батча;
- `results/initialization_experiment.png` - влияние инициализации весов;
- `results/base_metrics.csv` - accuracy основного обучения;
- `results/learning_rate_results.csv` - таблица точностей для разных скоростей обучения;
- `results/batch_size_results.csv` - таблица точностей для разных размеров батча;
- `results/initialization_results.csv` - таблица точностей для разных инициализаций.
